#ZOMBIESOUND

Приложения для прослушивание музыки на платформе SoundCloud
На просторах интернета уже достаточно давно гуляют разнообразные клиенты для прослушивания музыки, но в них постоянно чего-то не хватает.
Мы решили сделать что-то свое, объединить всевозможные удобные функции и перенести в одно приложение.
Изначально - проект локальный и не планировался к публикации в массы, но из-за частых вопросов - мы релизим открытый бета-тест программы, в котором готовы выслушать все баги и 
предложения по усовершенствованию.
